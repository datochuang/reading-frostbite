# Reading Frostbite

A reader's guide to the Frostbite announcement: a 25-page whiteboard deck (English) and five
interactive explainers (Traditional Chinese) on interaction nets, abstract machines, and what AI
changes in chip design.

Open `index.html`, or visit the GitHub Pages site of this repository.

This is one reader's notes. It is not affiliated with any company mentioned in it. Every Frostbite
number comes from the announcing company's own article and is pre-silicon; no independent check
was public as of November 2026. Corrections are welcome as issues.
